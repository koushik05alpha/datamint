# DataMint Docs

Documentation site for DataMint — the AI-powered lead generation & data enrichment engine.

**Live:** https://datamint-sable.vercel.app/

## Tech Stack

- Next.js (App Router)
- React
- Vercel (deployment)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to `master` — Vercel auto-deploys from the connected repo.
